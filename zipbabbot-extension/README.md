# 🤖 집밥봇 쿠팡 자동 담기 확장 프로그램 (Chrome & Naver Whale 공용)

집밥봇 대시보드에서 30일 식단 식재료를 쿠팡 장바구니에 **1초 만에 원클릭으로 자동 담아주는** 공식 확장 프로그램입니다.
파이썬이나 터미널 명령어 없이, **일반 윈도우 PC나 맥북의 크롬 또는 네이버 웨일 브라우저**에서 누구나 바로 사용할 수 있습니다!

---

## 🚀 10초 초간단 설치 방법 (1회만 등록)

### [방법 1] 구글 크롬(Chrome) 브라우저
1. **크롬(Chrome) 브라우저**를 엽니다.
2. 주소창에 `chrome://extensions` 를 입력하고 이동합니다.
3. 화면 우측 상단의 **[개발자 모드]** 스위치를 켭니다 (ON).
4. 좌측 상단의 **[압축해제된 확장 프로그램을 로드합니다]** 버튼을 누릅니다.
5. 압축을 푼 폴더 (`zipbabbot-extension`)를 선택하면 **설치 완료!** 🎉

### [방법 2] 네이버 웨일(Whale 🐳) 브라우저
1. **네이버 웨일(Whale) 브라우저**를 엽니다.
2. 주소창에 `whale://extensions` 를 입력하고 이동합니다.
3. 화면 우측 상단의 **[개발자 모드]** 스위치를 켭니다 (ON).
4. 좌측 상단의 **[압축해제된 확장 앱 로드]** 버튼을 누릅니다.
5. 압축을 푼 폴더 (`zipbabbot-extension`)를 선택하면 **설치 완료!** 🎉
*(또는 `zipbabbot-extension` 폴더를 웨일 확장 프로그램 관리 화면 안으로 마우스 드래그해도 바로 설치됩니다)*

---

## 🛒 사용 방법: "PC에서 1초 만에 담고 ➔ 결제는 폰으로!"

1. 크롬 또는 네이버 웨일에서 집밥봇 대시보드를 엽니다.
2. 원하는 주차의 **[⚡ 주차별 품목 한 번에 담기]** ➔ **[🚀 한 번에 담기 시작]** 버튼을 누릅니다.
3. 확장 프로그램이 브라우저 백그라운드에서 모든 품목을 최적 로켓배송 상품으로 **쿠팡 장바구니에 진짜로 쏙 담아줍니다!**
4. 다 담긴 후 **스마트폰 쿠팡 앱을 열면 실시간으로 100% 동기화**되어 있으므로, 침대나 이동 중에 편하게 결제만 누르시면 끝납니다.
